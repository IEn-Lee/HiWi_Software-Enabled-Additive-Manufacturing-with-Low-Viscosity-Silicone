# Free segment-level optimizer v1.1 — corrected FIFO-weight model

This file is based on the supplied free segment-level optimizer. The optimization architecture is unchanged: every adjustable segment remains an independent timing decision, Stage 1 remains the global minimax feasibility LP, Stage 2 remains the sampled ideal-target LP, and optional multi-round TRUE-FIFO relinearization/acceptance is unchanged.

## Only substantive model correction

The old residence model treated the already-averaged baseline `t_in` as one physical event on the G-code time axis. That is removed.

The corrected model reconstructs FIFO dependencies from `cycle`, `cycle_local`, and `V_mm3`:

- Each FIFO piece gets a linear `t_out` expression from the G-code timing variables.
- For each cycle after the first, the destination piece consumes previous-cycle volume in FIFO order.
- `t_in(i) = sum_k w(i,k) * t_out(k)`.
- `tau(i) = t_out(i) - t_in(i)`.

Because E/volume and order are unchanged, the FIFO weights remain fixed and the model stays linear.

## Unchanged optimizer behavior

- one independent control per adjustable segment
- no control blocks
- original relative speed distribution is not preserved
- extrusion/travel F bounds unchanged
- dwell P bounds unchanged
- `max_relative_F_change` / `max_relative_P_change` unchanged
- Stage 1 minimax logic unchanged
- Stage 2 target logic unchanged
- `--stage1_only` unchanged
- multi-round `--iterations` behavior unchanged
- TRUE validation and acceptance priority unchanged
- G-code patching unchanged

## New required input columns

The corrected FIFO model additionally requires:

- `cycle`
- `cycle_local`

The existing `V_mm3` column is also used to reconstruct the FIFO source weights.

## New diagnostics

Each round prints baseline reconstruction checks for:

- tau
- t_in
- t_out

For a CSV generated by the compatible TRUE FIFO builder, these should be near numerical / CSV rounding error before optimization.

## Validation performed

The file compiles successfully and passed a synthetic three-cycle test with unequal FIFO source volumes, travel, dwell, and deliberately non-uniform independent segment timing changes. The corrected LP residence equations matched an independent FIFO-volume backfill result to floating-point precision (maximum error about 8.9e-16 s).
